### Answer any 4 out of the given 6 questions

### 11. What is the significance of the Table of Contents feature in LibreOffice Writer?

**Answer:**

The Table of Contents (TOC) feature helps organise a document in a proper and structured way. It automatically creates a list of headings and subheadings along with their page numbers.

This makes it easier for readers to quickly find topics in a long document. The Table of Contents also updates automatically when new headings are added or page numbers change.

### 12. Briefly explain the purpose of the Subtotal tool in LibreOffice Calc.

**Answer:**

The Subtotal tool is used to automatically calculate totals for grouped data in a worksheet. It can find the sum, average, count, maximum or minimum values for selected groups.

For example, a list of salespersons and their monthly sales can be grouped to calculate the total sales for each salesperson in every month.

### 13. Give any two prerequisites before consolidating data in Calc.

**Answer:**

- The data should be arranged in a proper tabular format, with rows and columns.
- Each data range should have the same structure, headings and layout.
- There should be no blank rows or columns within the data range.

### 14. How are data and information different from each other?

**Answer:**

**Data** are raw facts and figures that have no clear meaning on their own. They are unprocessed and unorganized.

For example, the marks `45, 67, 89, 76` are data.

**Information** is processed and organized data that has meaning and is useful for decision-making.

For example, saying that the average marks of the class are 69% converts data into useful information.

Common causes include:

### 21. An electronic gadget shop keeps records of its products in a table named Gadgets.

The Gadgets table has the following columns:

- `ItemID` — Primary Key
- `ItemType`
- `Size`
- `Quantity`
- `Price`
- `Supplier`

The billing data is stored in a table named Bill:

- `BillNo` — Primary Key
- `ItemID`
- `Price`
- `CustName`
- `CustPhoneNo`

**(a) Name any two Gadgets-table columns where duplicate values are allowed.**

**Answer:**

`ItemType` and `Supplier` may contain duplicate values. `Quantity` and `Price` may also contain duplicate values.

**(b) If Gadgets already contains `ItemID = 1001`, can a new record use the same value?**

**Answer:**

No. `ItemID` is a primary key and primary-key values must be unique.

**(c) Is it possible to store product photos in a new Gadgets column?**

**Answer:**

Yes. Images can be stored using the **BLOB** (Binary Large Object) data type.

In real-world applications, it is common to store only the image file path as a `VARCHAR` field and keep the image in a server folder.

**(d) Briefly explain the principle of referential integrity for the Gadgets and Bill tables.**

**Answer:**

Referential integrity ensures that every `ItemID` in the Bill table matches an existing `ItemID` in the Gadgets table. This prevents entering a bill for a product that does not exist in the Gadgets table.
