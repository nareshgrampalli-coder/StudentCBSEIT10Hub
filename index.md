# Information Technology Class 10 Question Answer

This website provides solutions for **CBSE Class 10 IT Code 402**. The course is divided into **Part A: Employability Skills** and **Part B: Subject Specific Skills**.

Part A contains 5 units carrying 10 marks in the board examination. Part B contains 4 units carrying 40 marks and is the most important section for students preparing to score well.

## Career Opportunities After Studying IT

Information Technology provides a strong foundation for many career options after Class 10. Students can explore:

- Software development
- Cloud computing
- Cyber security
- Data analysis
- Web technologies
- Information and communications technology

IT skills are in demand across industries. Students aiming for engineering or technology careers should build strong fundamentals and practice regularly.
