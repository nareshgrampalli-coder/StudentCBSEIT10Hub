## <u>Chapter 1: Introduction to Styles</u>

### 1. What are styles? What are the advantages of using styles?

**Answer:**

**Styles** are predefined formatting attributes used in digital document processing to apply consistent formatting to text and other elements.

Advantages of using styles include:

- Consistency throughout the document
- Efficiency in formatting
- Flexibility when making changes
- Improved accessibility for users with assistive technologies

### 2. What are the different types of style in LibreOffice Writer?

**Answer:**

LibreOffice Writer provides six style categories:

- **Page style:** Defines the basic page layout, including page size, margins, headers, footers, footnotes, borders, and background.
- **Paragraph style:** Controls formatting that begins and ends with pressing `Enter`, including tab stops, text alignment, line spacing, and borders.
- **Character style:** Formats selected blocks of letters or words, such as text color, size, and highlighting.
- **Frame style:** Organizes a document into sections that can have different appearances. It controls size, position, borders, and text placement around a picture.
- **List style:** Adds different numbering or bullet styles and specifies numeric formats.
- **Table style:** Formats tables using borders, text or border colors, text alignment, and different patterns or text colors.

### 3. What is the Fill Format option in LibreOffice Writer?

**Answer:**

Normally, a style must be applied separately to words at different locations. The **Fill Format** option provides a convenient way to apply the same style to these locations:

1. Select the style.
2. Use Fill Format to apply it repeatedly.
3. Move to and click each location where the style is required.

### 4. How can styles be loaded from a template?

**Answer:**

Styles can be copied from a template or another document:

1. Open the style menu and click **Load Style**.
2. Select the document or template containing the styles.
3. Click **OK** to copy the styles into the current document.

### 5. How can a style be modified?

**Answer:**

A style can be modified by:

- Loading or copying styles from another document or template.
- Updating a style from a selected text sample.

### 6. How can we create our own styles?

**Answer:**

There are two ways to create a style:

- **Creating a new style from a selection:** Copy the formatting from existing text to create a new style. The style applies only to the current document and is not saved in the template.
- **Dragging and dropping to create a style:** Drag a text selection into the **Styles and Formatting** window to create a new style.

## <u>Chapter 2: Working with Images</u>

### 7. List three methods of inserting images in LibreOffice Writer.

**Answer:**

Three methods are:

- Inserting an image using drag and drop
- Inserting an image using copy and paste
- Inserting an image by linking

### 8. What is the purpose of inserting an image by linking?

**Answer:**

Linking is useful when several copies of the same image are required.

Instead of storing the complete image for every insertion, the document stores its reference. This reduces document size because the actual image is saved only once as a separate file alongside the document.

### 9. Explain five graphic filters.

**Answer:**

- **Invert:** Changes the colors in a color image and gives brightness to a grayscale image.
- **Solarization:** Adds excessive-light effects to a photograph.
- **Posterize:** Reduces the number of colors so the picture looks like a painting.
- **Charcoal:** Displays the image as a charcoal sketch.
- **Mosaic:** Combines groups of pixels into a single-color area.

### 10. What does resizing an image in LibreOffice Writer mean?

**Answer:**

**Resizing** means reducing or enlarging an image.

A quick and easy method is to drag the image’s sizing handles.

### 11. Explain image cropping.

**Answer:**

**Image cropping** removes unwanted parts of an image while keeping only a selected portion.

Two important Crop page options are:

- **Keep scale:** Cropping does not affect the image scale. This is the default option.
- **Keep image size:** The image size remains constant, causing positive crop values to enlarge or negative crop values to shrink and possibly distort the image.

### 12. What is grouping objects in LibreOffice Writer?

**Answer:**

Grouping allows several shapes to behave as one object without affecting their individual size or position.

After grouping:

- Every shape becomes a member of the group.
- Applying a change to one member affects all members.

### 13. What is arrangement in LibreOffice Writer?

**Answer:**

**Arrangement** determines the position of a drawing relative to overlapping drawings or text.

Arrangement options include:

- Bring to Front
- Send to Back
- Bring Forward One
- Send Back One

### 14. What is anchoring in LibreOffice Writer?

**Answer:**

**Anchoring** links an object to a specific position in the document.

An image or drawing can be anchored to:

- A page
- A paragraph
- A character
- A frame

### 15. What is alignment in LibreOffice Writer?

**Answer:**

Alignment controls the vertical or horizontal position of an image relative to its anchor.

There are six alignment styles:

- Three horizontal alignment styles
- Three vertical alignment styles

### 16. What is text wrapping in LibreOffice Writer?

**Answer:**

**Text wrapping** controls the placement of an image relative to text.

Text wrapping options include:

- Wrap Off
- Page Wrap
- Optimal Page Wrap
- Wrap Left
- Wrap Right
- Wrap Through

## <u>Chapter 3: Advanced Features of Writer</u>

### 17. What do you mean by a table of contents?

**Answer:**

A **table of contents** automatically lists the headings and subheadings used in a document.

The entries are also hyperlinked to their corresponding sections.

The table of contents uses elements such as:

- **E#:** Chapter number
- **E:** Entry text
- **T:** Tab stop
- **LS:** Start of a hyperlink
- **LE:** End of a hyperlink

### 18. What do you mean by the hierarchy of headings in a table of contents?

**Answer:**

LibreOffice Writer supports up to **10 heading levels**, from `H1` to `H10`.

These headings are applied to document headings and help Writer create a table of contents automatically.

### 19. What are templates? What are the advantages of using templates?

**Answer:**

A **template** is a preset layout used to create professional or formal documents easily.

A template can contain:

- Text
- Graphics
- Styles
- Designs

Advantages include:

- Making document creation easier
- Saving time by providing styles
- Keeping the audience interested

### 20. What is Track Changes in LibreOffice Writer?

**Answer:**

**Track Changes** records all changes made to the original document.

The original author can review each change and either:

- Accept the change
- Reject the change

### 21. What is comparing documents in LibreOffice Writer?

**Answer:**

LibreOffice Writer can compare the original document with a reviewed document.

The user can then choose the option that best suits the required changes.
